# AI E-Commerce Business Analyst Agent Dataset

Synthetic, realistic e-commerce dataset created for an AI Data Analyst Agent project.

Files:
- customers.csv: customer profile and segment
- products.csv: product catalog, cost and selling price
- orders.csv: order-level sales transactions
- support_tickets.csv: customer service interactions
- payments.csv: payment/reconciliation data

Suggested AI Agent questions:
1. How many customers and orders are there?
2. What is total revenue and profit estimate?
3. Which city has the highest revenue?
4. Which product category is most profitable?
5. What are the top 10 customers?
6. Which customers are at high churn risk?
7. Which issue type has the longest resolution time?
8. Are there payment/order reconciliation mismatches?
9. What changed in monthly revenue?
10. Give 5 actionable business recommendations.

Project stack:
n8n + Ollama + SQL/Python + Power BI
